# AI Customer Query Assistant 🤖

This is a full-stack AI-powered chatbot project built to handle customer queries using natural language processing.

## 🛠️ Project Features

- ✅ React.js frontend with chat UI
- ✅ Node.js + Express backend
- ✅ Hugging Face AI model integration (`mistralai/Mistral-7B-Instruct-v0.1`)
- ✅ Role-based authentication for Admin and Core users
- ✅ Original code, free model—no OpenAI API key needed
